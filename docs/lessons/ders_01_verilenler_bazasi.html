Bu dərsdə siz Azərbaycan Respublikası Elm və Təhsil Nazirliyinin Təsərrüfathesablı Əsaslı Tikinti və Təchizat İdarəsi üçün qurulan ERP sisteminin verilənlər bazası qatını sıfırdan quracaqsınız. Layihə DeepSeek-5 ERP adlanır və tam idarəetməsi süni intellekt tərəfindən dəstəklənir.

Bu dərsin sonunda aşağıdakılara nail olacaqsınız:

  • PostgreSQL 18 serverini quraşdıracaqsınız;
  • deepseek_erp_v6 adlı baza və deepseek_admin istifadəçisi yaradacaqsınız;
  • 13 sxem (ref, layihe, satinalma, maliyye, kadr, hesabat + ai, sened, risk, keyfiyyet, logistika, tehlike, audit) quracaqsınız;
  • 48 cədvəlin hər birini yaradıb, məntiqini anlayacaqsınız;
  • İki seed skripti ilə nümunə məlumatlar yükləyəcəksiniz;
  • Bazanın düzgün qurulduğunu yoxlamağı öyrənəcəksiniz.
Tələb olunan bilik: Əsas SQL (CREATE TABLE, INSERT, SELECT), psql əmrləri, əməliyyat sistemi terminalı ilə işləmək. PostgreSQL ilə heç işləməmisinizsə, bu dərs sizə addım-addım kömək edəcək.
Real fayllar: database/schemas/01_create_tables.sql, database/schemas/02_create_tables_ek.sql, database/seeds/02_seed_data.sql, database/seeds/03_seed_new_tables.sql, database/migrations/*.sql, database/00_drop_all.sql

4.1. ref sxemi — İstinad məlumatları

CədvəlMəqsədiƏsas xüsusiyyətləri

is_novu nümunəsi — hierarxik struktur:

CREATE TABLE IF NOT EXISTS ref.is_novu (
    is_novu_id  SERIAL PRIMARY KEY,
    parent_id   INTEGER REFERENCES ref.is_novu(is_novu_id),
    ad          VARCHAR(150) NOT NULL,
    kod         VARCHAR(20),
    vahid       VARCHAR(20) DEFAULT 'm²',
    aktif       BOOLEAN NOT NULL DEFAULT TRUE,
    created_at  TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at  TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

Burada parent_id öz cədvəlinə işarə edir — "Tikinti-quraşdırma işləri" (TQ) ana kateqoriyadır, "Yeni binanın tikintisi" (TQ-01) isə onun uşaqdır.

5 Migrasiya Faylları

Layihədə database/migrations/ qovluğunda iki əlavə dəyişiklik var:

5.1. 002_create_users.sql — İstifadəçilər (auth)

Auth sxemi və istifadəçi cədvəli. Parollar backend tərəfindən bcrypt ilə heşlənir (Dərs 3-də görəcəksiniz). Rol məhdudiyyəti CHECK ilə:

CREATE SCHEMA IF NOT EXISTS auth;

CREATE TABLE IF NOT EXISTS auth.users (
    user_id     SERIAL PRIMARY KEY,
    username    VARCHAR(50)  NOT NULL UNIQUE,
    email       VARCHAR(150) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    full_name   VARCHAR(150),
    role        VARCHAR(30) NOT NULL DEFAULT 'istifadeci'
                CHECK (role IN ('admin','mudir','muellim','istifadeci','auditor')),
    is_active   BOOLEAN NOT NULL DEFAULT TRUE,
    last_login  TIMESTAMPTZ,
    created_at  TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at  TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

5.2. 005_add_progres.sql — Layihə progress kolonu

Dərs 2-də yaradılacaq trigger bu kolonu mərhələ progressindən avtomatik hesablayacaq:

ALTER TABLE layihe.layihe
    ADD COLUMN IF NOT EXISTS progres NUMERIC(5,2) NOT NULL DEFAULT 0;

6 Seed Məlumatlarının Yüklənməsi

Seed = bazanın ilkin (nümunə) məlumatlarla doldurulması. İki seed faylı var.

6.1. 02_seed_data.sql — 6 əsas sxemin məlumatları

Bu fayl aşağıdakıları doldurur:

  • 13 iqtisadi rayon (Bakı, Qarabağ, Naxçıvan...) — ON CONFLICT (ad) DO NOTHING ilə təkrardan qorunma;
  • 9 şəhər (Bakı, Gəncə, Mingəçevir...);
  • 7 müəssisə növü və 7 təhsil müəssisəsi (müştəri bazası);
  • 7 + 6 = 13 iş növü (hierarxik: TQ → TQ-01, TQ-02...);
  • 7 + 7 = 14 material növü (SB → SB-01, SB-02...);
  • 5 layihə statusu və 5 layihə (L-2026-001 ... 005);
  • 7 mərhələ, 6 layihə materialı;
  • 5 tender statusu, 3 tender, 5 iştirakçı;
  • 2 müqavilə (MQ-2026-015, MQ-2026-008), 3 material tədarükü;
  • 5 + 5 = 10 büdcə maddəsi, 7 xərc, 4 ödəniş;
  • 7 vəzifə, 8 işçi, 4 təyinat.

Seed üsulunun vacib nümunəsi — subquery ilə FK dəyərlərini adla tapmaq:

INSERT INTO ref.muessise (seher_id, nov_id, ad, voen, unvan, telefon) VALUES
((SELECT seher_id FROM ref.seher WHERE ad='Bakı'),
 (SELECT nov_id FROM ref.muessise_novu WHERE ad='Ümumtəhsil məktəbi'),
 'N. Nərimanov adına 20 nömrəli tam orta məktəb', '1234567890',
 'Bakı, Nərimanov r.', '+994 12 123 45 01')
ON CONFLICT (ad) DO NOTHING;

ON CONFLICT DO NOTHING — əgər eyni adlı sətir varsa, səhv vermədən atlanır. Bu, seed faylını dəfələrlə icra etməyi təhlükəsiz edir.

7.3. Bir neçə nümunə sorğu

-- Layihələr və büdcələri
SELECT kod, ad, plan_budce FROM layihe.layihe ORDER BY kod;

-- AI agentləri və bağlı olduqları modellər
SELECT a.ad AS agent, a.vezife, m.ad AS model, m.provider
FROM ai.ai_agent a
JOIN ai.ai_model m ON m.model_id = a.model_id
WHERE a.aktif = TRUE;

8 Təkrarlama Tapşırığı

Ev tapşırığı: Aşağıdakıları özünüz edin — bu dərsə baxmadan:
  1. PostgreSQL 18-i quraşdırın və versiyanı yoxlayın.
  2. deepseek_erp_v6 bazası və deepseek_admin istifadəçisini yaradın (parol Deepseek2026).
  3. 13 sxemi əl ilə (psql-də) yaradın: ref, layihe, satinalma, maliyye, kadr, hesabat, ai, sened, risk, keyfiyyet, logistika, tehlike, audit.
  4. ref.region cədvəlini əl ilə yazın (SERIAL PK, ad UNIQUE, kod UNIQUE, aktif BOOLEAN, timestamplar).
  5. İki seed faylını icra edin və layihe.layihe-də 5 sətir olduğunu yoxlayın.
  6. İzah edin: ON CONFLICT DO NOTHING nəyə xidmət edir? NUMERIC(14,2) nə deməkdir?
Bu addımda nə öyrəndin? PostgreSQL quraşdırma və baza yaratma; sxemlərin məntiqi bölgüsü (13 sxem); 48 cədvəlin hər birinin məqsədi; xarici açarlar (FK), özünə istinad (self FK), CHECK məhdudiyyətləri, soft delete, GENERATED STORED sütunu; transaksiya blokları; seed fayllarında ON CONFLICT və subquery ilə FK tapma üsulları.
