0 Dərsin Məqsədi

Bu dərs backend-ə AI idarəetmə qatını əlavə edir. Məqsəd — AI modellərinin (DeepSeek və Anthropic Claude) vahid interfeysdən çağırılması, tapşırıqların ai sxemindəki cədvəllərə yazılması və mock rejimində real API xərci olmadan test edilməsidir.

  • aiService — iki provider-i (DeepSeek + Anthropic) birləşdirən vahid xidmət;
  • promptBuilder — sorğu mətnlərini (prompt) verilənlər bazası məlumatlarından qurur;
  • aiModel — ai sxem cədvəlləri ilə işləyən model (ai_teyinat, ai_agent, ai_log);
  • aiController + aiRoutes — HTTP API;
  • Mock rejimi — AI_MODE=mock olduqda real API çağırışı etmədən nəticə qaytarmaq.
Real fayllar: backend/.env (AI_MODE, DEEPSEEK_*, ANTHROPIC_*), database/schemas/02_create_tables_ek.sql (ai sxemi), database/seeds/03_seed_new_tables.sql (AI seed məlumatları)

3 aiService — İki Providerli Vahid Xidmət

src/services/aiService.js — ən vacib fayl. AI_MODE-a görə mock və ya live rejimini seçir:

require('dotenv').config();

// Provider konfiqurasiyası .env-dən
const AI_MODE = process.env.AI_MODE || 'mock';   // 'mock' | 'live'

const PROVIDERS = {
  deepseek: {
    baseUrl: process.env.DEEPSEEK_BASE_URL || 'https://api.deepseek.com',
    apiKey: process.env.DEEPSEEK_API_KEY,
    model: process.env.DEEPSEEK_MODEL || 'deepseek-chat',
  },
  anthropic: {
    baseUrl: process.env.ANTHROPIC_BASE_URL || 'https://api.anthropic.com',
    apiKey: process.env.ANTHROPIC_API_KEY,
    model: process.env.ANTHROPIC_MODEL || 'claude-sonnet-5',
  },
};

// DeepSeek-ə sorğu (OpenAI-uyumlu /chat/completions)
async function callDeepSeek(prompt, sistem) {
  const { baseUrl, apiKey, model } = PROVIDERS.deepseek;
  const res = await fetch(`${baseUrl}/chat/completions`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${apiKey}`,
    },
    body: JSON.stringify({
      model,
      messages: [
        { role: 'system', content: sistem },
        { role: 'user', content: prompt },
      ],
      temperature: 0.3,
    }),
  });
  if (!res.ok) throw new Error(`DeepSeek xətası: ${res.status} ${await res.text()}`);
  const data = await res.json();
  return {
    metin: data.choices[0].message.content,
    tokens: data.usage.total_tokens,
  };
}

// Anthropic Claude-a sorğu (messages API)
async function callAnthropic(prompt, sistem) {
  const { baseUrl, apiKey, model } = PROVIDERS.anthropic;
  const res = await fetch(`${baseUrl}/v1/messages`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'x-api-key': apiKey,
      'anthropic-version': '2023-06-01',
    },
    body: JSON.stringify({
      model,
      max_tokens: 4096,
      system: sistem,
      messages: [{ role: 'user', content: prompt }],
    }),
  });
  if (!res.ok) throw new Error(`Anthropic xətası: ${res.status} ${await res.text()}`);
  const data = await res.json();
  return {
    metin: data.content[0].text,
    tokens: data.usage.input_tokens + data.usage.output_tokens,
  };
}

// Mock rejim — real API xərci olmadan test üçün nümunə cavab
function callMock(prompt, tapşırıqNovu) {
  // Realist görünən nümunə nəticə — AI_MODE=mock olduğu üçün heç bir API çağırılmır
  const cavablar = {
    budce_prognozu: {
      prognoz_budce: 823000,
      sapma_faizi: -3.2,
      tovsiye: 'Material alışını rübün sonuna saxlayın',
    },
    tender_qiymetlendirme: {
      en_yaxsi_teklif: 2210000,
      tovsiye_edilen: 'AZKURTİK MMC',
      eminlik: 87,
    },
    risk_analizi: {
      kritik_risk: 'material_qiymet',
      derece: 42,
      mudaxile_plani: 'Alternativ təchizatçı ilə opsion müqavilə',
    },
  };
  return {
    metin: JSON.stringify(cavablar[tapşırıqNovu] || {
      nəticə: 'Mock nəticə', tapşırıq: tapşırıqNovu,
    }),
    tokens: 0,
  };
}

// Vahid giriş nöqtəsi
async function execute({ provider = 'deepseek', tapşırıqNovu, prompt, sistem }) {
  if (AI_MODE === 'mock') return callMock(prompt, tapşırıqNovu);

  if (provider === 'anthropic') return callAnthropic(prompt, sistem);
  return callDeepSeek(prompt, sistem);
}

module.exports = { execute, AI_MODE, PROVIDERS };
İki provider niyə? DeepSeek iqtisadi və sürətlidir (analitika, adi tapşırıqlar); Claude daha güclüdür (strateji planlama, mürəkkəb qərarlar). ai_model cədvəlində hər agent öz modelinə bağlıdır — provider sahəsi seçimi aparır.

4 promptBuilder — Promptların Qurulması

src/services/promptBuilder.js baza məlumatlarını insan oxuya bilən prompt mətninə çevirir:

// Sistem mesajı — AI-ya rolu verir
function sistemMesaji(rol) {
  const rolar = {
    planlayici: 'Sən təcrübəli tikinti layihələri planlayıcısısan. ' +
                'Layihə mərhələlərini, vaxt və resurs bölgüsünü hazırlayırsan.',
    tender_analitiki: 'Sən tender təkliflərini qiymətləndirən maliyyə analitikisən. ' +
                      'Qiymət və texniki meyarlara görə ən optimal təklifi tövsiyə edirsən.',
    risk_nezaretcisi: 'Sən layihə risklərini izləyən risk idarəçisisən. ' +
                      'Risk dərəcəsini (ehtimal × təsir) hesablayıb müdaxilə planı təklif edirsən.',
  };
  return rolar[rol] || 'Sən ERP sisteminin AI köməkçisisən.';
}

// Tapşırıq növünə görə prompt qurur
function build({ tapşırıqNovu, layihe, verilənlər }) {
  const baza = [
    `Verilənlər bazasından məlumatlar:`,
    `Layihə: ${layihe.kod} — ${layihe.ad}`,
    `Plan büdcə: ${layihe.plan_budce} AZN`,
    `Cari xərc: ${verilənlər.xerc_umumi || 'yoxdur'} AZN`,
    `Progress: ${verilənlər.progres || 0}%`,
    '',
  ].join('\n');

  const istəklər = {
    budce_prognozu: 'Bu məlumatlara əsasən layihənin tamamlanma büdcəsini proqnozlaşdır. ' +
                    'Sapma faizini göstər və qənaət üçün 1-2 tövsiyə ver.',
    tender_qiymetlendirme: 'Tender təkliflərini qiymət meyarına görə dərəcələndir, ' +
                           'ən yaxşı təklifi və əminlik faizini qeyd et.',
    risk_analizi: 'Risk amillərini təhlil edərək hər biri üçün ehtimal və təsir ver, ' +
                  'kritik riski və müdaxilə planını qeyd et.',
  };

  return `${baza}\nTapşırıq: ${istəklər[tapşırıqNovu] || verilənlər.sual || 'Təhlil apar.'}`;
}

module.exports = { sistemMesaji, build };

5 aiModel — Verilənlər Bazası İnteqrasiyası

src/models/aiModel.js Dərs 1-də qurduğumuz ai sxem cədvəlləri ilə işləyir:

const { pool } = require('../config/db');

// Aktiv agentləri modelləri ilə birlikdə gətir
async function agentler() {
  const { rows } = await pool.query(
    `SELECT a.agent_id, a.ad, a.vezife, m.provider, m.model_ref
     FROM ai.ai_agent a
     JOIN ai.ai_model m ON m.model_id = a.model_id
     WHERE a.aktif = TRUE`
  );
  return rows;
}

// Yeni AI tapşırığı yarat
async function teyinatYarat({ agent_id, layihe_id, teyinat_novu, giris_json, prompt, yaradan }) {
  const { rows } = await pool.query(
    `INSERT INTO ai.ai_teyinat
       (agent_id, layihe_id, teyinat_novu, giris_json, prompt, status, yaradan)
     VALUES ($1,$2,$3,$4,$5,'islemede',$6)
     RETURNING teyinat_id`,
    [agent_id, layihe_id, teyinat_novu, giris_json, prompt, yaradan]
  );
  return rows[0];
}

// Nəticəni yaz, statusu 'hazir' et
async function teyinatBitir(teyinatId, cixis_json) {
  await pool.query(
    `UPDATE ai.ai_teyinat
     SET cixis_json = $2, status = 'hazir',
         tamamlanma_tarixi = NOW(), updated_at = NOW()
     WHERE teyinat_id = $1`,
    [teyinatId, cixis_json]
  );
}

// Xəta halı — status 'xesver'
async function teyinatXeta(teyinatId) {
  await pool.query(
    `UPDATE ai.ai_teyinat SET status = 'xesver', updated_at = NOW()
     WHERE teyinat_id = $1`, [teyinatId]
  );
}

// İcra loqu — token və xərc izləmə
async function logYaz({ teyinat_id, agent_id, hadise, mesaj, tokens, xerc }) {
  await pool.query(
    `INSERT INTO ai.ai_log (teyinat_id, agent_id, hadise, mesaj, serf_olunan_tokens, serf_olunan_xerc)
     VALUES ($1,$2,$3,$4,$5,$6)`,
    [teyinat_id, agent_id, hadise, mesaj, tokens, xerc]
  );
}

module.exports = { agentler, teyinatYarat, teyinatBitir, teyinatXeta, logYaz };

6 aiController — Əsas Sorğu Axını

const aiModel = require('../models/aiModel');
const aiService = require('../services/aiService');
const promptBuilder = require('../services/promptBuilder');

// POST /api/ai/sorgu
async function sorgu(req, res, next) {
  try {
    const { agent_id, layihe_id, teyinat_novu, verilənlər, provider } = req.body;

    // 1. Agent və layihə məlumatını tap
    const agent = (await aiModel.agentler()).find(a => a.agent_id === agent_id);
    if (!agent) return res.status(404).json({ xeta: 'Agent tapılmadı' });

    const layiheRes = await require('../models/layiheModel').findById(layihe_id);

    // 2. Prompt qur
    const prompt = promptBuilder.build({
      tapşırıqNovu: teyinat_novu,
      layihe: layiheRes,
      verilənlər,
    });
    const sistem = promptBuilder.sistemMesaji(agent.vezife);

    // 3. Tapşırığı bazaya yaz (islemede)
    const teyinat = await aiModel.teyinatYarat({
      agent_id, layihe_id, teyinat_novu,
      giris_json: verilənlər || {}, prompt,
      yaradan: req.user?.user_id || 1,
    });

    // 4. AI-a göndər (mock və ya live)
    const nəticə = await aiService.execute({
      provider: provider || agent.provider,
      tapşırıqNovu: teyinat_novu,
      prompt, sistem,
    });

    // 5. Nəticəni JSON olaraq saxla (cavab mətnidirsə parse et)
    let cixis;
    try { cixis = JSON.parse(nəticə.metin); }
    catch { cixis = { metin: nəticə.metin }; }
    await aiModel.teyinatBitir(teyinat.teyinat_id, cixis);

    // 6. Loq yaz
    await aiModel.logYaz({
      teyinat_id: teyinat.teyinat_id, agent_id,
      hadise: 'bitdi', mesaj: 'Tapşırıq uğurla tamamlandı',
      tokens: nəticə.tokens || 0,
      xerc: 0,
    });

    res.json({ teyinat_id: teyinat.teyinat_id, status: 'hazir', cixis });
  } catch (e) {
    // Xəta olarsa statusu xesver et
    next(e);
  }
}

// GET /api/ai/teyinatlar — AI tapşırıqlarının siyahısı
async function teyinatlar(req, res, next) {
  try {
    const { rows } = await require('../config/db').pool.query(
      `SELECT t.teyinat_id, a.ad AS agent, t.teyinat_novu, t.status,
              t.tesdiq_status, t.netice_qiymeti, l.kod AS layihe
       FROM ai.ai_teyinat t
       JOIN ai.ai_agent a ON a.agent_id = t.agent_id
       LEFT JOIN layihe.layihe l ON l.layihe_id = t.layihe_id
       ORDER BY t.teyinat_id DESC`
    );
    res.json(rows);
  } catch (e) { next(e); }
}

module.exports = { sorgu, teyinatlar };

8.4. Xəta idarəçiliyi — provider xətaları

Live rejimdə API xətası olarsa, aiService xətanı qaldırır və aiController onu emal edir. Tapşırığın statusu xesver olmalıdır:

async function sorgu(req, res, next) {
  try {
    ...
  } catch (e) {
    // Tapşırıq varsa statusu xesver et
    if (req.teyinat_id) await aiModel.teyinatXeta(req.teyinat_id);
    next(e);
  }
}

10 Təkrarlama Tapşırığı

Ev tapşırığı: Dərsə baxmadan:
  1. aiService-də yeni bir provider (məsələn openai) necə əlavə edərdiniz? İzah edin.
  2. callMock-a material_planlamasi üçün nümunə cavab əlavə edin.
  3. promptBuilder.build-a keyfiyyet_hesabati tapşırıq növü əlavə edin.
  4. Bir AI tapşırığını işə salıb ai_log-da qeydin yarandığını yoxlayın.
  5. İzah edin: AI_MODE=live olduqda nə dəyişir? Mock-un üstünlükləri nələrdir?
Bu addımda nə öyrəndin? Provider abstraksiyası (vahid interfeyslə iki fərqli AI API-si); fetch ilə REST çağırışları; Anthropic Messages API vs DeepSeek Chat Completions; prompt mühəndisliyi (sistem mesajı + kontekst + tapşırıq); AI tapşırıq həyat dövrünün (islemede → hazir/xesver) bazada izlənməsi; mock rejimin dəyəri.
